# Qore: Delivery & Orders Admin Dashboard

A **React admin dashboard** for a delivery business: managing orders, customers, products, vehicles and staff from one place.

> 🚧 Front-end prototype: the layout, navigation and order screens are built; the back end is not connected yet.

## Features

- 🧭 Sidebar navigation: Dashboard, Orders, Customers, Products, Promotions, Vehicles, Deliveries, Staff
- 📋 Orders page with **order planning** and **add new order**
- 📊 Dashboard page
- 📱 Responsive layout with a top navbar and collapsible sidebar

## Tech stack

React 18 · React Router 6 · Ant Design · Bootstrap 5

## Run locally

```bash
cd frontend
npm install
npm start
```
